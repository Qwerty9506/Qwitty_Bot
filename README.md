# Qwitty — исправленная версия

## Установка

Положите рядом файлы `main.py`, `admin.py`, `userbot.py`, `guard.py`, `tools.py` и `requirements.txt`. Замените старые версии целиком, добавьте новый `admin.py`. Запуск остаётся прежним: `python main.py`. Используйте Python 3.10 или новее.

Переменные BOT_TOKEN, API_ID, API_HASH, SUPABASE_URL, SUPABASE_KEY остаются прежними. Для существующего перезапуска через Render используются RENDER_API_KEY и RENDER_SERVICE_ID. Новые таблицы в Supabase для этой правки не нужны: сохраняется существующая схема `config(id, data)`.

## Что изменено

- В `admin.py` вынесены административные обработчики, статистика, просмотр аккаунтов, групп, жалоб и управление перезапуском.
- Главное админ-меню: три строки по две кнопки и отдельная четвёртая строка возврата.
- Все кнопки возврата в личном интерфейсе выделены в собственные строки, включая списки с пагинацией и часовые пояса.
- Открытая статистика обновляется раз в секунду, кнопки «Обновить» нет. HTML передаётся с parse_mode=HTML, теги не выводятся текстом. При выходе обновление прекращается. Размер БД запрашивается отдельно с кэшем 5 минут; счётчики времени меняются ежесекундно. При RetryAfter соблюдается пауза Telegram.
- Имена пользователей и названия групп, которые бот выводит в своих экранах, оформлены ссылками. Кнопки остаются обычным текстом. Для закрытых групп используются доступные ссылки; доступ к самой группе по-прежнему определяется Telegram.
- Профиль и видимый список активных сессий обновляют имя примерно раз в минуту, если включено время в профиле. В карточке берётся фактическое имя Telegram, включая время.
- Жалобы без причины учитываются в общем числе и списке жалоб, но не вытесняют три последние непустые причины. Старые пустые записи отфильтрованы при отображении. Открытые жалобы больше не удаляются автоматически через 30 дней.
- Tools показывает краткое уведомление «Функция ещё в разработке!» без открытия нового экрана.

## АнтиНакрутка

Настройка включается отдельно для каждой группы. Порог — **50 и более разных аккаунтов за 60 секунд**. До достижения порога проверяется скользящий интервал; после достижения порога окончание волны привязано к первой учтённой записи. По окончании минуты начинается постоянная блокировка участников этой волны, включая тех, кто успел войти позднее до её завершения. Один вход, пришедший одновременно через chat_member и служебное сообщение, учитывается один раз.

Боту необходимы права администратора и блокировки участников. Владельцы, действующие администраторы и сам бот не блокируются. Выполнение идёт последовательно: при большом числе участников или лимите Telegram завершение блокировки может занять дополнительное время. Неудачные попытки остаются в очереди; при выключении функции её окно и очередь отменяются.

Таймер, участники волны и незавершённые блокировки записываются в БД и восстанавливаются после запуска.

## Сохранение данных

Настройки аккаунтов, сессии, настройки групп, скрытые группы, жалобы и глобальные блокировки сохраняются в существующей Supabase. Изменение пользовательских настроек ожидает результат записи, вместо прежнего немедленного возврата успеха из очереди. Изменения групп также отправляются до завершения операции.

Перед отправкой пользовательские изменения записываются в локальную SQLite-очередь `config_outbox.sqlite3`, групповые — в `guard.sqlite3`. При сбое сети записи остаются в очереди. После обычного перезапуска незавершённые локальные изменения имеют приоритет над старой удалённой копией и отправляются повторно. Сбой чтения всех настроек при запуске не подменяется пустой базой.

Временный архив удалённых и отредактированных сообщений по-прежнему не выгружается в Supabase. Одноразовые коды входа и пароль 2FA не записываются в постоянные настройки.

Подтверждённые записи Supabase восстанавливаются и на новом экземпляре сервера. Если Supabase недоступна и одновременно теряется локальный диск, неподтверждённые изменения восстановить неоткуда. Для сохранности такой очереди при замене хоста нужен постоянный диск; пути можно задать через CONFIG_OUTBOX_SQLITE и GUARD_SQLITE. Бот показывает предупреждение о неподтверждённой записи.

## Проверка

Выполнены компиляция, импорт модулей и 13 автоматических проверок с подменой сетевых вызовов: разметка, клавиатуры, секундное обновление и отмена задач, минутное обновление профиля, Tools, причины жалоб, порог и дубли входов, права администратора, повтор блокировки после RetryAfter, восстановление из Supabase и локальной очереди, сохранение при ошибке записи.

Живые аккаунты, Telegram-группы, Render и ваша Supabase для тестов не использовались. После замены файлов проверьте работу в тестовой группе с выданными правами.
